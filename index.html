Gesah Warga

Sampaikan saran, masukan, laporan keamanan, maupun kondisi lingkungan langsung kepada perangkat yang dipilih.

Panduan Singkat

  • Gunakan bahasa yang jelas dan sopan agar perangkat mudah memahami kebutuhan Anda.
  • Untuk keamanan & ketertiban, arahkan laporan ke Linmas agar respon lebih cepat.
  • Semua pengiriman akan tercatat otomatis di riwayat lokal browser Anda.
  • Agar foto dan berita terbaru terlihat di semua perangkat, admin perlu mengunduh HTML terbaru dan memublikasikannya ke GitHub.

Menghubungkan database online ...

Data online belum bisa dibaca

Server Firebase menolak membaca siTengoroPublic/primary atau foto siTengoroMedia/.... Kode HTML tidak dapat mengubah izin server.

  1. Di Firebase Console → Firestore Database → Rules, pilih proyek yang sama dengan aplikasi.
  2. Cadangkan aturan yang sudah ada. Tambahkan aturan get publik untuk dua koleksi SI-TENGORO (jangan menghapus aturan aplikasi lain).
  3. Klik Publish, kemudian tekan Coba Lagi di bawah ini.
Buka Firebase Console
Untuk foto yang belum pernah diunggah, admin tetap perlu mengunggahnya. Status ini tidak akan hilang hanya dengan mengganti file GitHub jika Rules Firebase masih menolak akses.
