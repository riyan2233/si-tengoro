Instal Aplikasi SI-TENGORO

Bisa untuk semua versi HP Android (Sangat Ringan)

HP Android Anda mendukung Instalasi Sekali Klik!

Cara menampilkan ikon aplikasi SI-TENGORO di menu layar utama HP Android Anda:

1

Klik Ikon Titik Tiga (⋮) di Pojok Kanan Atas

Pada browser Chrome atau browser bawaan HP Android Anda.

2

Pilih "Tambahkan ke Layar Utama" atau "Instal Aplikasi"

(Dalam Bahasa Inggris: Add to Home Screen / Install App).

3

Tekan "Tambah" / "Instal"

Selesai! Ikon SI-TENGORO akan muncul di menu HP Anda seperti aplikasi biasa tanpa menghabiskan memori.

Berhasil!
